Search reference

Words search for a case insensitive substring in the message. Quotes keep spaces together: "connection refused". Multiple words form one substring in the order entered. Fields match exact values and are case sensitive.

SelectorValueExample

until:Exclusive enduntil:2026-09-21

Time values

Use now, now-30m, now+2h, a date such as 2026-09-21, or a timestamp with an offset such as 2026-09-21T09:00:00-04:00. Durations accept seconds (s), minutes (m), hours (h), days (d), and weeks (w). Dates begin at midnight UTC. Both relative bounds in a query use the same current time.

since:2026-09-21 until:2026-09-22 searches one UTC day.
